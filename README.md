# Эмулятор командной оболочки ОС

**Практическая работа №1 | Вариант №4**

## 1. Общее описание
Разработать эмулятор для языка оболочки ОС. Необходимо сделать работу эмулятора  как  можно  более  похожей  на  работу  в  командной  строке  UNIX-подобной ОС.

**Текущий статус этапов разработки:**

- [x] Этап 2. Конфигурация
- [x] Этап 3. VFS
- [ ] Этап 4. Основные команды
- [ ] Этап 5. Дополнительные команды

## 2. Описание всех функций и настроек
На текущем этапе реализован базовый цикл (REPL), парсинг параметров запуска и работа с виртуальной файловой системой (VFS). Доступны следующие функции:
* **Конфигурация (Этап 2):** Эмулятор принимает аргументы командной строки `--vfs` (путь к JSON-файлу файловой системы) и `--script` (путь к файлу с командами для стартового выполнения).
* **Виртуальная файловая система (Этап 3):** Загружается из JSON-файла в оперативную память. Поддерживается хранение структуры папок и содержимого файлов (в формате base64).
* **Парсинг ввода:** Разделение строки пользователя на основную команду и список аргументов.
* **Раскрытие переменных окружения:** Поддержка подстановки системных переменных (например, `%USERNAME%` или `$VAR_NAME`) через `os.path.expandvars`.
* **Доступные команды:**
  * `ls` — команда просмотра директорий (выводит переданные аргументы, логика VFS в разработке).
  * `cd` — смена текущей директории (выводит переданные аргументы, логика VFS в разработке).
  * `conf-dump` — выводит текущие пути к файлу VFS и стартовому скрипту.
  * `vfs-init` — сбрасывает VFS к состоянию по умолчанию (пустая корневая папка `{"/": {}}`) и полностью очищает физический JSON-файл.
  * `exit` — выход из эмулятора.
