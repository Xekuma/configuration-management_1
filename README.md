# Эмулятор командной оболочки ОС

**Практическая работа №1 | Вариант №4**

## 1. Общее описание
Разработать эмулятор для языка оболочки ОС. Необходимо сделать работу эмулятора как можно более похожей на работу в командной строке UNIX-подобной ОС.

**Текущий статус этапов разработки:**

- [x] Этап 2. Конфигурация
- [x] Этап 3. VFS
- [x] Этап 4. Основные команды (ls, cd, find, head, cal)
- [x] Этап 5. Дополнительные команды (mkdir, rmdir)

## 2. Описание реализованных функций
Проект полностью завершен. Реализованы все базовые и дополнительные команды работы с виртуальной файловой системой. Любые модификации структуры директорий происходят исключительно в оперативной памяти.

* **Работа с VFS:** Файловая система загружается из JSON в оперативную память. Содержимое файлов хранится в формате base64. В приглашении командной строки динамически отображается текущая директория.
* **Раскрытие переменных окружения:** Поддержка подстановки системных переменных (например, `%USERNAME%`) через `os.path.expandvars`.
* **Доступные команды:**
  * `cd [путь]` — смена текущей директории. Поддерживает абсолютные и относительные пути.
  * `ls [путь]` — вывод содержимого текущей или указанной директории.
  * `find [путь]` — рекурсивный обход и вывод дерева файлов и каталогов.
  * `head [файл]` — декодирует содержимое файла из base64 и выводит первые 10 строк.
  * `cal [месяц] [год]` — выводит календарь.
  * `mkdir [имя]` — создание новой директории в текущей папке VFS (только в памяти).
  * `rmdir [имя]` — удаление пустой директории из VFS (только в памяти).
  * `conf-dump` — выводит текущие пути к файлу VFS и стартовому скрипту.
  * `vfs-init` — сбрасывает VFS к состоянию по умолчанию и очищает физический JSON-файл.
  * `exit` — завершение работы эмулятора.
